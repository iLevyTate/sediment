Sediment

Type a GitHub repository. Watch its history settle as sediment — time left to right, each band a region of the tree, thickness the code alive at that moment.

Public repositories only. No token needed for a first look.

Exact line counts

This page measures file bytes, because that is all the GitHub API returns without a request per commit. Run it locally to replay every blob and count lines exactly: 

npx github:iLevyTate/sediment

Put it in your README

The action renders an animated GIF on a schedule and commits it to a branch, so a plain image link in your README stays current. 

uses: iLevyTate/sediment@main

Host it anywhere

Download page gives you one self-contained HTML file — no server, no network, no build step. Drop it on your own site.
