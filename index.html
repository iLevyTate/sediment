Sediment

Type a GitHub repository and watch its history settle as sediment. Time runs left to right, each band is a region of the tree, and thickness is the code alive at that moment.

Exact line counts

This page measures file bytes. That is all the GitHub API returns without spending one request per commit. Run it on a clone to replay every blob and count lines exactly. 

npx github:iLevyTate/sediment

Put it in your README

The action renders a GIF on a schedule and pushes it to a branch. A plain image link in your README then shows the repository as it is now, not as it was the day you ran it. 

uses: iLevyTate/sediment@main

Host it anywhere

Download page gives you one self-contained HTML file. No server, no network, no build step. Put it on your own site.
